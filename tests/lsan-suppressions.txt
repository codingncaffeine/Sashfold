# Leaks LeakSanitizer finds in libraries that are not ours, for the tests
# that load them (tests/CMakeLists.txt). Each names the library alone.

# NVIDIA's Vulkan driver opens a D-Bus connection it never closes, and the
# Vulkan loader unloads the driver at vkDestroyInstance, which leaves the
# connection unreachable (measured 2026-09-23 with test_vp9: gone when the
# NVIDIA driver is hidden, still there when the loader is kept loaded).
# Sashfold itself never speaks D-Bus.
leak:libdbus-1.so
