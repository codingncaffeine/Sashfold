# The Sashfold 100: a hundred pages of the web, rendered every night by
# Sashfold itself and shown at https://sashfold.com/sashfold100/.
#
# The sites come from the Tranco list (https://tranco-list.eu), the
# research ranking of the web's most visited domains, and each row carries
# its site's rank on the list named below. The rows were chosen to cover
# the web a reading browser meets: an encyclopedia in nine languages,
# documentation, news, government, blogs, link aggregators, the standards
# themselves, the plain and table-built web, image-heavy pages, the TLS
# report card, and the ten most visited sites of all, as they are.
#
# Records are tab-separated:
#   list      <id>  <date>  <url>
#   category  <id>  <title>  <description>
#   row       <id>  <category>  <rank>  <url>  <flags>  <note>
# The rank is the row's registrable domain's place on the list. flags is
# "-" or a comma-separated list: rtl marks a right-to-left page (the row is
# shown greyed, since bidirectional text is not written yet); refuse marks
# a page whose certificate must be refused for the row to count as right.
#
# tools/sashfold100.sh renders every row (build/sashfold --render, one
# process per page under a time limit) and writes the dashboard.

category	wikipedia	Wikipedia	The same article, "Web browser", in nine languages: Latin script with its accents, Japanese, Chinese, Cyrillic, and two right-to-left scripts.
category	docs	Documentation	The reference pages programmers keep open: long text, code blocks, tables, sidebars.
category	news	News	Front pages and sections of the world's newsrooms, as they are on the night of the render.
category	gov	Government	Public sites built to be read by everyone.
category	blogs	Blogs and their engines	Sites built with the tools most personal blogs run on, and the hosted platforms.
category	aggregators	Link aggregators	Dense lists of links, the oldest layout on the web.
category	specs	The standards	The specifications the engine is written against, rendered by it.
category	plain	The plain web	Text-first and table-built pages: the web as it was written before scripts.
category	images	Pictures	Pages whose point is the pictures on them.
category	tls	The TLS report card	badssl.com's deliberately broken certificates: the right answer for each bad one is a refusal, with no way through.
category	top	The ten most visited	The top of the list as it stands — mostly applications that draw themselves with scripts, shown here as they arrive without any.
category	projects	Projects and communities	Source hosting, question sites, and the homes of languages and distributions.
